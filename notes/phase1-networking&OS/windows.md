# Windows Fundamentals

## Event Viewer

### What is Event Viewer?

Event Viewer is a built-in Windows tool that records system, application, and security events. It helps administrators troubleshoot issues and investigate suspicious activity.

### Main Log Categories

| Log | Purpose |
|------|---------|
| Application | Events generated by applications |
| Security | Login attempts, account activity, permission changes |
| System | Operating system and hardware events |

### Why it matters

Security logs are one of the first places SOC analysts check during an investigation. They can reveal failed logins, successful logins, account changes, and other important events.

## Task Manager

### What is Task Manager?

Task Manager shows the programs, processes, services, and system resources currently running on a Windows machine.

### What you can do

- View running processes
- Check CPU, Memory, Disk, and Network usage
- End unresponsive processes
- View startup applications
- Monitor system performance

### Why it matters

Unexpected or unfamiliar processes can indicate malware or unauthorized activity.

## Basic PowerShell Commands

### Get-Process

Displays all currently running processes.

```powershell
Get-Process
```

### Get-Service

Lists all Windows services.

```powershell
Get-Service
```

### Get-EventLog

Retrieves logs from Event Viewer.

```powershell
Get-EventLog -LogName Security
```

### Why it matters

PowerShell allows administrators and SOC analysts to quickly gather system information, investigate incidents, and automate repetitive tasks.
